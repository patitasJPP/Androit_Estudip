# Prototipo RF-05 y RF-06 conservado

Estos archivos pertenecen a una implementación anterior del registro de pérdidas y la búsqueda de coincidencias. Se conservaron con sus rutas originales bajo este directorio porque sus modelos, repositorios y estados ya no coinciden con el flujo activo conectado a Supabase.

El código de este directorio está fuera de `app/src` y no participa en la compilación de Android. El flujo vigente está en `app/src/main/java/com/Jair/practica/view/perdida/ReportePerdidaActivity.kt`, `CoincidenciasActivity.kt` y sus modelos actuales.
